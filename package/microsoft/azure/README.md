# Microsoft Azure Schema

Suite-level (umbrella) AuditgraphDB schema for Microsoft Azure. Defines the
shared Azure classes, interfaces, enums, and fields that Azure product
schemas and collectors build on — tenants, subscriptions, resource groups,
resource providers, and the `AzureResource` interface.

Published as `@zerobias-org/schema-microsoft-azure`
(catalog package `microsoft.azure.schema`).

Previously published from the `auditlogic/schema` repository as
`@auditlogic/schema-microsoft-azure`; this package supersedes it.
